📋 Project Overview

Earthy Concepts is a premium Ayurvedic wellness e-commerce platform. The website sells wellness concepts through products, primarily teas and supplements.

Brand Philosophy

  • Sells wellness concepts practiced through simple daily routines
  • Products are the tools that enable these concepts
  • Does NOT make medical claims or sell quick fixes
  • Premium, modern, trust-building tone

📊 Data Models

Product Type

interface Product {
  id: string;
  name: string;
  slug: string;
  tagline: string;
  description: string;
  price: number;              // Base price in AED
  subscriptionPrice: number;  // 15% discount
  category: ProductCategory;
  concept: WellnessConcept;
  image: string;
  ingredients: string[];
  howToUse: string;
  bestTime: string;
  rating: number;
  reviewCount: number;
  inStock: boolean;
  isBestseller?: boolean;
  isNew?: boolean;
}

type ProductCategory = 'teas' | 'topicals' | 'supplements' | 'bundles' | 'gifts';

type WellnessConcept = 
  | 'calm'
  | 'womens-balance'
  | 'immunity'
  | 'metabolic-balance'
  | 'skin-glow'
  | 'heart-wellness';

Bundle Type

interface Bundle {
  id: string;
  name: string;
  slug: string;
  description: string;
  products: Product[];         // Included products
  originalPrice: number;       // Sum of individual prices
  bundlePrice: number;         // 15% discount
  subscriptionPrice: number;   // Additional 15% for subscription
  savings: number;             // Amount saved
  savingsPercent: number;      // Usually 15%
  concept: WellnessConcept;
  image: string;
}

Cart Item Type

interface CartItem {
  product: Product | Bundle;
  quantity: number;
  isSubscription: boolean;
}

interface CartState {
  items: CartItem[];
  addItem: (product: Product | Bundle, isSubscription?: boolean) => void;
  removeItem: (productId: string) => void;
  updateQuantity: (productId: string, quantity: number) => void;
  toggleSubscription: (productId: string) => void;
  clearCart: () => void;
  subtotal: number;
  itemCount: number;
}

🔄 State Management

The application uses React Context API for global state management:

CartContext

  • Manages shopping cart state
  • Persists cart to localStorage
  • Provides add, remove, update, toggle subscription actions
  • Calculates subtotal with region pricing

RegionContext

  • Manages current region/currency selection
  • Provides price formatting utilities
  • Persists selection to localStorage

Future State (with Backend)

  • AuthContext - User authentication state
  • UserContext - User profile, orders, subscriptions
  • TanStack Query for server state (products, orders, etc.)

🗄️ Database Schema (Supabase/PostgreSQL)

Users Table

CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email TEXT UNIQUE NOT NULL,
  full_name TEXT,
  phone TEXT,
  region TEXT DEFAULT 'AE',
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Enable RLS
ALTER TABLE users ENABLE ROW LEVEL SECURITY;

Addresses Table

CREATE TABLE addresses (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  type TEXT DEFAULT 'shipping', -- 'shipping' | 'billing'
  full_name TEXT NOT NULL,
  address_line_1 TEXT NOT NULL,
  address_line_2 TEXT,
  city TEXT NOT NULL,
  state TEXT,
  postal_code TEXT NOT NULL,
  country TEXT NOT NULL,
  phone TEXT,
  is_default BOOLEAN DEFAULT false,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

Products Table

CREATE TABLE products (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  slug TEXT UNIQUE NOT NULL,
  name TEXT NOT NULL,
  tagline TEXT,
  description TEXT,
  price_aed DECIMAL(10,2) NOT NULL,
  subscription_price_aed DECIMAL(10,2),
  category TEXT NOT NULL,
  concept TEXT NOT NULL,
  image_url TEXT,
  ingredients TEXT[],
  how_to_use TEXT,
  best_time TEXT,
  rating DECIMAL(2,1) DEFAULT 0,
  review_count INTEGER DEFAULT 0,
  in_stock BOOLEAN DEFAULT true,
  is_bestseller BOOLEAN DEFAULT false,
  is_new BOOLEAN DEFAULT false,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

Bundles Table

CREATE TABLE bundles (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  slug TEXT UNIQUE NOT NULL,
  name TEXT NOT NULL,
  description TEXT,
  concept TEXT NOT NULL,
  original_price_aed DECIMAL(10,2) NOT NULL,
  bundle_price_aed DECIMAL(10,2) NOT NULL,
  subscription_price_aed DECIMAL(10,2),
  savings_percent INTEGER DEFAULT 15,
  image_url TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE bundle_products (
  bundle_id UUID REFERENCES bundles(id) ON DELETE CASCADE,
  product_id UUID REFERENCES products(id) ON DELETE CASCADE,
  PRIMARY KEY (bundle_id, product_id)
);

Orders Table

CREATE TABLE orders (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  order_number TEXT UNIQUE NOT NULL,
  status TEXT DEFAULT 'pending', -- pending, confirmed, processing, shipped, delivered, cancelled
  subtotal_aed DECIMAL(10,2) NOT NULL,
  shipping_aed DECIMAL(10,2) DEFAULT 0,
  discount_aed DECIMAL(10,2) DEFAULT 0,
  total_aed DECIMAL(10,2) NOT NULL,
  currency TEXT DEFAULT 'AED',
  shipping_address JSONB,
  billing_address JSONB,
  stripe_payment_intent_id TEXT,
  stripe_subscription_id TEXT,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE order_items (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  order_id UUID REFERENCES orders(id) ON DELETE CASCADE,
  product_id UUID REFERENCES products(id),
  bundle_id UUID REFERENCES bundles(id),
  quantity INTEGER NOT NULL,
  price_aed DECIMAL(10,2) NOT NULL,
  is_subscription BOOLEAN DEFAULT false,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

Subscriptions Table

CREATE TABLE subscriptions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  stripe_subscription_id TEXT UNIQUE,
  stripe_customer_id TEXT,
  status TEXT DEFAULT 'active', -- active, paused, cancelled
  next_billing_date TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE subscription_items (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  subscription_id UUID REFERENCES subscriptions(id) ON DELETE CASCADE,
  product_id UUID REFERENCES products(id),
  bundle_id UUID REFERENCES bundles(id),
  quantity INTEGER DEFAULT 1,
  price_aed DECIMAL(10,2) NOT NULL
);

🔐 Authentication (Supabase Auth)

Supported Auth Methods

  • Email + Password
  • Magic Link (passwordless)
  • Google OAuth (optional)

Auth Flow

// Sign Up
const { data, error } = await supabase.auth.signUp({
  email: 'user@example.com',
  password: 'password',
  options: {
    data: {
      full_name: 'John Doe'
    }
  }
});

// Sign In
const { data, error } = await supabase.auth.signInWithPassword({
  email: 'user@example.com',
  password: 'password'
});

// Sign Out
await supabase.auth.signOut();

// Get Current User
const { data: { user } } = await supabase.auth.getUser();

💰 Pricing Logic

Discount Structure

  • Subscription: 15% off one-time price
  • Bundles: 15% off combined product prices
  • Bundle + Subscription: 15% + 15% (stacked)

Price Calculation

// One-time price
const price = product.price;

// Subscription price (15% off)
const subscriptionPrice = product.price * 0.85;

// Bundle price (15% off)
const bundlePrice = bundle.products.reduce((sum, p) => sum + p.price, 0) * 0.85;

// Bundle + Subscription (stacked discounts)
const bundleSubPrice = bundlePrice * 0.85;

// Price formatting utility
function formatPrice(priceAED: number, region: Region): string {
  const converted = priceAED * region.multiplier;
  return `${region.currencySymbol} ${converted.toFixed(0)}`;
}
